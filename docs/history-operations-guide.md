# 历史内容运营工作台使用手册

## 这次改版解决什么问题

历史知识模块原来擅长生成一篇完整的小红书图文稿。主题、朝代四件套、历史之最、封面提示词、评论回复和 Excel 数据导入都已经能用。

改版以后，这些能力仍然保留。页面上方新增六个工作区，把一次生成扩展成一套能长期使用的编辑流程。你可以自由增加内容方向，也可以停用不再适合账号的方向。朝代和历史之最继续放在内容生产页里，适合时再用，不占用固定栏目。

所有运营数据保存在项目原有的本地状态文件中。旧历史稿件可以继续打开和复制，新字段缺失时页面会按旧格式正常展示。

## 第一次打开先做三件事

进入历史知识模块后，默认看到今日工作台。

先填写账号名称、目标读者和内容承诺。内容承诺会随选题资料一起交给历史 Agent，用来约束成稿方向。每周目标用于判断发布日历是否排满，不会自动替你发布内容。

随后进入选题库，检查系统预置的六个内容方向。它们只是起步模板。你可以停用、删除，也可以增加城市史、女性史、战争后勤、地方史等新方向。

最后录入几条近期准备做的选题。刚记下的问题保持在待评估阶段。资料开始收集以后改为研究中。事实卡和角度都确认后，再推进到可生产。

## 六个工作区怎样使用

### 今日工作台

这里集中显示账号策略、生产漏斗、系统建议和正在推进的选题。

每天开始工作时先看系统建议。没有可生产选题时，先补研究。发布数量不足时，再安排日期。数据还没导入时，先完成数据同步。这样可以避免打开页面以后直接生成一篇与账号计划无关的稿子。

### 选题库

选题库负责管理内容方向、候选选题、研究资料、评分和生产状态。

新增选题时只要求填写一个清楚的问题。方向可以暂时留空。点击选题名称会展开详情，你可以继续补充切入角度、开头钩子、目标读者、风险提示和计划发布日期。

每个选题有八项评分。需求、好奇、反差、收藏、视觉、证据和延展分数越高越好，风险分数越低越好。列表中的综合分会把前七项相加，再减去风险分。这个分数适合帮助排序，最终决定仍然要结合账号定位和近期内容密度。

事实资料卡分为四级。

- A 级用于有直接证据支撑的内容，例如一手文献、出土材料或明确记录
- B 级用于主流研究普遍接受的解释
- C 级用于存在争议、只能限定表达的内容
- D 级用于无法确认或不应进入成稿的内容

资料卡至少填写资料名称和它能支撑的结论。引用信息、网址和备注可以通过接口继续补充。只要没有资料卡，或者存在 C 级与 D 级资料，生成稿就会显示发布前需事实复核。

点击生成以后，系统会把当前选题、方向、读者、角度、风险提示和资料卡交给历史 Agent。生成成功后，选题进入制作中，并关联本次稿件。

### 内容生产

这个工作区保留原有的全部生成能力。

主题模式适合临时输入一个问题。朝代模式仍会生成王朝兴衰录、皇帝图鉴、风云人物和历史冷知识四套稿件。历史之最模式仍会自动选择有比较依据的主题。

从选题库进入的稿件会多出运营素材包，其中包括多个候选标题、多个封面文字方案、续篇建议、约六十秒口播稿、内容 ID、关联方向和资料状态。

内容 ID 用来连接选题、生成稿和后续发布数据。发布前先处理事实复核提示，再复制标题、正文、封面提示词和各张图片提示词。

内容生产只处理选题到成稿。数据导入、表现复盘和评论回复分别放在后面的专用工作区，制作稿件时不会被运营数据打断。

### 发布日历

日历显示从今天开始的十四天排期。选题详情中填写日期后，会出现在对应日期。

可生产但没有日期的内容会进入待排期列表。直接选择日期后，状态会同步改为待发布。

日历只负责计划和状态管理，当前版本不会替你登录小红书或自动点击发布。正式发布后，把选题阶段改成已发布，并在下一次数据导入后检查是否成功匹配。

### 数据复盘

小红书数据总览和 Excel 导入入口都在这个工作区。导入笔记明细以后，系统按每篇笔记计算点赞率、收藏率、评论率、分享率和总互动率。分母统一使用浏览量。

页面使用中位数作为账号基线。少数爆款不会把基线拉得过高，低表现内容也更容易与同一账号的常态比较。

系统会尝试用标题匹配选题库。标题差异过大时可能匹配失败，因此建议发布时从运营素材包复制标题，并在发布后保留最终使用版本。

复盘建议目前会检查数据是否导入、选题数量、事实资料覆盖、可生产库存、排期数量和收藏率最高的内容。它负责提醒下一步动作，不会根据单篇数据自动改变史实规则。

### 评论洞察

截图识别、内容匹配、回复生成和回复草稿都在这个工作区。回复区保存的评论会按事实质疑、想看续集、没看懂、补充资料和观点讨论进行归类。每类会显示数量和代表性评论。

生成稿里的续篇建议也会集中出现在这里。点击加入选题库，就能把它变成新的候选选题。这样做几周以后，选题会逐渐来自真实读者问题。

## 推荐的日常流程

每天先打开今日工作台，看可生产库存和近期排期。接着处理一到两个研究中的选题，补资料卡和风险说明。确认资料以后把状态改为可生产，再从选题库点击生成。

生成完成后进入内容生产，比较候选标题和封面文字。检查事实复核状态，逐张检查图片文字和视觉还原风险。图文稿和口播稿都可以直接复制。

选好发布日期以后回到选题详情填写日期。发布完成后把状态改为已发布。每周至少导入一次小红书数据，再到数据复盘查看中位数和互动率变化。

评论积累到一定数量后，到评论洞察里处理事实质疑和追更请求。高频问题可以直接加入下一轮选题。

## 推荐的每周复盘方式

先看收藏率。历史知识内容的收藏通常能反映信息是否值得留存。随后看分享率，判断题材有没有转发给朋友的理由。评论率适合观察观点空间和读者疑问。点赞率可以参考，但不应单独决定下一周选题。

每次只改变一个主要变量。可以连续测试不同标题角度，也可以连续测试封面信息密度。不要同时更换题材、标题、封面和图文结构，否则数据出来以后很难判断哪项改变起了作用。

复盘后留下三个明确动作。保留一个表现稳定的做法，停止一个连续低于基线的做法，再安排一个新的小实验。

## 常见问题

### 我以后不想做朝代或历史之最了怎么办

不需要改代码。选题库中的内容方向可以随时新增、停用和删除。朝代与历史之最只保留在内容生产页，想用时再用。

### 为什么稿件显示需要事实复核

关联选题没有资料卡，或者资料中含有 C 级与 D 级内容。回到选题库补充可靠来源，确认争议表达，再重新生成或人工修订。

### 为什么数据没有匹配到选题

系统目前通过标题文本匹配。发布标题与选题名称差异很大时会失配。可以让选题名称更接近最终标题，后续也可以通过接口补充平台笔记 ID。

### 删除内容方向会不会删除选题

不会。关联选题会保留，并变成未分类。删除选题会移除它的运营资料，但不会删除已经生成的历史稿件。

### 数据导入失败怎样检查

确认上传的是小红书笔记列表明细表，文件格式为 xlsx 或 xls，并且工作表中存在笔记标题表头。系统会识别浏览、点赞、收藏、评论和分享等常见列名。

## 数据保存和备份

账号策略、方向、选题和资料卡跟随项目状态保存在 `.agent-zy-data/state.json`。历史主题去重档案仍保存在 `.agent-zy-data/history/topic-archive.json`。

项目已有数据同步功能时，这些状态会继续走现有同步流程。手工备份前先停止正在进行的生成任务，随后复制整个 `.agent-zy-data` 目录。
