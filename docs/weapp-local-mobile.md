# 微信小程序本地局域网使用说明

本文档说明如何在不发布、不上线、不配置公网 HTTPS 域名的情况下，用手机微信访问本项目的小程序版本。

## 运行方式

小程序只负责手机端界面，真实数据仍然来自你电脑上运行的控制面服务：

```text
手机微信预览版小程序
  -> http://电脑局域网 IP:4378
  -> apps/control-plane
  -> .agent-zy-data
```

这不是正式发布版，只适合你自己的手机、微信开发者工具和同一路由器局域网。

## 首版功能

- 首页：检测后端连接、配置 API 地址、查看近期任务和关键摘要。
- 梦幻西游交易：查看收益概览、库存、近期交易；新增/删除物品交易；新增/删除角色、召唤兽、装备资产记录。
- 孩子食谱：查看孩子概况、今日餐食、近期备注；新增餐食记录；新增状态备注；生成并保存食谱计划。

首版不包含本机文件整理、照片重命名、桌面自动化、屏幕监控、图片/视频上传能力，因为这些能力依赖电脑本地文件或桌面权限，不适合放到手机小程序里操作。

## 1. 启动电脑端后端

在项目根目录执行：

```bash
HOST=0.0.0.0 PORT=4378 npm run dev:control-plane
```

`HOST=0.0.0.0` 很关键。默认 `127.0.0.1` 只允许电脑本机访问，手机访问不到。

## 2. 获取电脑局域网 IP

macOS 常用命令：

```bash
ipconfig getifaddr en0
```

如果电脑使用有线网络，可能是：

```bash
ipconfig getifaddr en1
```

假设输出是：

```text
192.168.1.20
```

那么小程序里的 API 地址应填写：

```text
http://192.168.1.20:4378
```

## 3. 导入微信开发者工具

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择：

```text
apps/weapp
```

4. AppID 可以先使用测试号或你自己的小程序 AppID。`project.config.json` 里默认是 `touristappid`，如果要真机预览，通常需要在开发者工具中换成可预览的 AppID。
5. 打开“详情” -> “本地设置”，勾选：

```text
不校验合法域名、web-view、TLS 版本以及 HTTPS 证书
```

本地局域网 HTTP 请求依赖这个设置。

## 4. 在开发者工具里配置 API 地址

打开小程序首页，在“API 地址”里填写：

```text
http://电脑局域网IP:4378
```

例如：

```text
http://192.168.1.20:4378
```

点击“保存”，再点击“检测”。显示“连接正常”后就可以使用。

## 5. 手机真机使用

1. 确认手机和电脑连接同一个 Wi-Fi。
2. 确认电脑后端仍在运行：

```bash
HOST=0.0.0.0 PORT=4378 npm run dev:control-plane
```

3. 在微信开发者工具点击“预览”，用手机微信扫码。
4. 手机打开预览版后，进入首页，确认 API 地址是电脑局域网 IP。
5. 点击“检测”，正常后即可进入“梦幻”或“食谱”tab 操作。

## 常见问题

### 手机检测失败

优先检查：

- 手机和电脑是否在同一个 Wi-Fi。
- API 地址是否是电脑局域网 IP，而不是 `127.0.0.1`。
- 后端是否用 `HOST=0.0.0.0` 启动。
- macOS 防火墙是否拦截 Node.js 入站连接。
- 路由器是否开启了 AP 隔离或访客网络隔离。

### 开发者工具可以访问，手机不行

通常是以下原因：

- 小程序仍配置成 `http://127.0.0.1:4378`。手机里的 `127.0.0.1` 指手机自己，不是电脑。
- 手机不在同一个局域网。
- 电脑 IP 变化了，需要重新填写 API 地址。
- 没有打开真机调试/预览环境中的调试能力。

### 食谱生成失败

食谱生成需要后端模型配置可用。先在现有 Web 端确认模型配置、API Key 和默认模型能正常调用。

### 数据会保存在哪里

仍然保存在电脑项目的 `.agent-zy-data` 下。小程序不保存业务数据，只保存一个本地 API 地址。

## 安全边界

这种模式会把电脑的 `4378` 端口暴露给同一局域网设备。建议只在可信 Wi-Fi 下使用。后续如果要长期使用，可以给控制面增加一个本地访问 token，小程序请求时带上 token，避免同网段设备误访问。
